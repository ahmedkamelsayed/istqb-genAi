# ISTQB CT-GenAI — Study Hub

A self-contained, offline study pack for the **ISTQB® Certified Tester, Specialist Level — Testing with Generative AI (CT-GenAI) v1.0** exam.

## 👉 Start here
Double-click **`index.html`** — it links everything and works offline in any modern browser. (All summaries are now styled HTML pages, so they open nicely in the browser too.)

## What's inside
```
index.html                     ← study hub / landing page
exams/                          ← 5 timed, auto-graded exams (40 Q · 46 pts each)
  official-istqb-exam-A.html   ← Official ISTQB Sample A (verified vs ISTQB answer key)
  astqb-sample-exam.html       ← Official ASTQB sample (verified vs ASTQB answer key)
  practice-exam-B.html         ← Original questions, same blueprint (options shuffle each attempt)
  practice-exam-C.html         ← Original questions, fresh scenarios
  practice-exam-D.html         ← Original questions, distinct from B & C
```

## Exam at a glance
- **40 questions · 46 points · 65% to pass (≥30) · 60 minutes**
- Cognitive levels K1 (recall), K2 (understand), K3 (apply)
- Prerequisite: ISTQB Foundation Level (CTFL)
- Heaviest chapter by far: **Chapter 2 – Prompt Engineering (~35%)**, which holds 5 of the 6 two-point K3 questions.

## Mock exam features
Select answers · flag questions for review · skip & return via the navigator grid · live countdown timer (auto-submits at 0) · **Finish** → score + pass/fail, per-chapter breakdown, and a full review showing every question as ✔ correct / ✗ incorrect / ➖ skipped / 🚩 flagged, **with the reason each option is right or wrong**. Filter the review by status. Progress auto-saves in the browser.
